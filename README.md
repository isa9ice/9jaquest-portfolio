# 9jaQuest — CBT & Learning Platform

**Learn · Practise · Compete**

9jaQuest is an education-focused web application project combining computer-based testing (CBT), class-based learning resources, academic assessments, and learner performance tracking.

This is a **public project portfolio** prepared to demonstrate the engineering work. The operational source code, production settings, and development history are maintained in a separate private repository.

## Product overview

The project brings related educational workflows into one application:

- **Learning experience:** Class- and subject-based resources, including learning-video sections.
- **Learner profiles:** Registration, authentication, parent-linked learner profiles, and dashboards.
- **Computer-based assessments:** Assessment selection, question delivery, answer submission, and results.
- **Performance feedback:** Answer review, learner progress views, and assessment leaderboards.
- **Administration:** Interfaces for managing assessments, questions, learning videos, and related content.

These capabilities are reflected in the inspected project repository. **Their availability in any public deployment may differ**, and a listed feature should not be read as a claim of independently verified production readiness.
